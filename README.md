# Projet Tic Tac Toe

Ce projet a été réalisé en trio dans le cadre de ma formation à la plateforme. Il s'agit d'un jeu de Tic Tac Toe développé en Python.

## Membres du projet

- **[Sofian Boubahri](https://github.com/ton-github)** : Responsable du développement principal et de l'implémentation du jeu.
- **[Aurélie Parseghian](https://github.com/aurelie-parseghian)** : Collaborateur pour la logique du jeu et la gestion des entrées.
- **[Dehlia Neiss](https://github.com/dehlia-neiss)** : Collaborateur pour la conception du jeu et l'amélioration de l'interface utilisateur.

## Description

Le projet consiste en un jeu interactif de Tic Tac Toe où les utilisateurs peuvent jouer l'un contre l'autre.
